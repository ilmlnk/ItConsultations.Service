# 📘 ItConsultations

ITConsultations is a RESTful API for managing private IT consultations. It allows users (coaches and students) to simplify process of creating, viewing, updating consultations, writing articles, creating forums, manage clients, schedules etc.

# ⚙️ Installation & Setup
1. Make sure you have .NET SDK installed.
2. Install Node.js if you are using ![frontend](https:://github.com/ilmlnk/ItConsultations.Frontend) (click to learn more).
3. Configure `appsettings.json`.
4. Run the project.
